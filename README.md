Bargain Beacon — a Black Friday deal finder of real, checked deals from Australian stores. 93 deals, each with its store, store link, sale price, usual price, discount and check time, plus a verdict on whether it is really a deal (NEW LOW, STRONG DEAL, GOOD PRICE or ROUTINE). Search and filters by category, store and discount all work; sorting puts the best deals first.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The site is static files under `app/` — no build step, no network request.
